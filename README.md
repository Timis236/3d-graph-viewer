# Overview
A program which uses the glut / freeglut library to generate a 3D graph, with several different mathematical functions available to be graphed / visualized. The GL folder contains all necessary glut / freeglut files to use the program, and should be placed inside of your include folder in order for the program to run properly (in case you don't already have it).

Users are able to explore the graph / grid by moving around the camera with their cursor. Additionally, opening the menu allows the user to choose between the different graphs to display, as well as zooming in and out or resetting the camera.
